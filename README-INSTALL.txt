ABOUTME FOOD MAZE GAME

This ZIP contains a standalone maze game for replacing the old final
"how many years" question.

FILES
- maze-game.html
- maze-game.css
- maze-game.js

FEATURES
- Woman character: 👩
- Arrow-key movement (plus mobile arrow buttons)
- Maze walls and finish line
- Good foods:
  Coffee, Bread, Cheese Bread, Burger, Fried Chicken
- Bad foods:
  Ramen/Noodles, Crab Food, Coke/Soda, ALL Cakes, Candy
- Each bad food collected deducts 1 point.
- 5 good foods gives a +5 maze score.
- Exactly 3 good foods gives a +1 maze score.
- Other good-food totals score by the number collected.
- The maze score is saved as localStorage key "mazeBonus".

IMPORTANT
Because the original repository files were not supplied as an attachment,
this ZIP is the game component rather than a blind replacement of your
existing quiz files. After attaching the original repo ZIP, the final game
can be wired directly into its existing question/score/results system
without guessing its variable names.
